# VFX Gallery
![v1.16.0](https://img.shields.io/badge/version-1.16.0-brightgreen)

Десктопный инструмент для управления видео-референсами.
Просматривайте, тегируйте и организуйте видеоколлекции в приложении Windows — без облака и без браузера.

## Возможности

- Галерея с автопревью и тегами
- Быстрый поиск по тегам и коллекциям
- Trim и Multicut — нарезка фрагментов
- Импорт видео по ссылке (YouTube и др.)
- Автоматические обновления

## Установка

1. Скачайте `VFX-Gallery-<версия>-windows-portable.exe` из раздела [Releases](../../releases)
2. Запустите двойным кликом (Python и `.bat` не нужны)
3. При первом запуске выберите папку с видео в окне приложения

## Обновление с предыдущих версий

Библиотека видео, `.vfxgallery` и `config.local.json` сохраняют формат. Меняется только запуск (окно приложения вместо браузера на localhost:5000).

- Обновитесь через in-app update **или** распакуйте новый релиз поверх старой папки (не удаляйте `config/` и папку видео).
- Если папка не запрашивается — галерея откроется с теми же роликами (те же hash).
- Если запрашивается — укажите ту же папку видео, что раньше.
- Закладка `http://127.0.0.1:5000` больше не нужна. Старые ключи LAN / public / пароль в config игнорируются.

## Требования

- Windows 10 / 11
- Доступ в интернет (только для обновлений и скачивания видео)
